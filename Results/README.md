# Generated results

This folder receives tabular and spatial outputs produced by the analytical scripts. Generated results are excluded from version control by default until the final publication files have been selected and checked.

Principal outputs include:

- the complete Very High-suitability candidate list;
- physical-assessment and screening results;
- alternative-weight sensitivity summaries;
- population-buffer sensitivity summaries; and
- robust top-22 candidate comparisons.

The final supplementary tables can be added here after their contents have been verified for public release.
